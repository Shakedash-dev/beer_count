# Sound credits

Source clips for the "beer logged" rotation. The app ships converted copies
(`android/app/src/main/res/raw/beer_sound_N.ogg`, trimmed, mono, level
matched); regenerate them with `python3 tool/convert_sounds.py`. Rotation
order is filename order, so `beer_sound_1` is the first file listed here.
